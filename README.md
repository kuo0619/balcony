# 陽台物品配置器 Balcony item layout tool

成大建築系大四設計課（郭妍希）：台南陽台、外推與雨遮研究的輔助工具。

線上版：https://kuo0619.github.io/balcony/

- 依真實尺寸在平面、立面、剖面擺放陽台必要物品
- 檢查重疊、室外機與熱水器預留空間、門扇與走道
- 自動排列與「固定深度、最短長度」計算

---

# 陽台日照剖面圖 Balcony sun profile

線上版：https://kuo0619.github.io/balcony/sun/

- 選擇城市、日期（夏至／冬至）、陽台朝向與時間，看陽光在陽台剖面上的射入與照到的範圍
- 以剖面角（profile angle）計算雨遮、外擴欄桿與鄰棟的遮陰
- 同時顯示平面圖與太陽軌跡
